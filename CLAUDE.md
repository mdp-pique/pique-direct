# Pique Direct

Direct booking site for Pique Properties, shown to guests as **Pique Lifestyle** (Michael Stead 11-25, MDP agreed; `SITE.name`, legal name Pique Properties Inc.; owners see Pique Properties at piqueproperties.com) (Edmonton, Canmore, Calgary). Next.js App Router on Vercel, content and booking from the Hospitable Public API. Separate from the internal ops app (`mdp-pique/pique-ops`) on purpose: nothing here touches its database or automations.

## How it works
- `src/lib/hospitable/client.ts` is the only code that calls Hospitable (`HOSPITABLE_API_TOKEN`). Reads are cached (1 h content, 5 min calendar) under the `hospitable` tag; `POST /api/revalidate` (bearer `REVALIDATE_SECRET`) refreshes everything.
- Booking: `/api/availability` (calendar) and `/api/quote` (Hospitable Direct quote). The quote returns Hospitable's checkout link; payment goes to Pique's Stripe through Hospitable, and the booking lands in Hospitable as a `direct` reservation, so the ops app's automations (ID check, pet fee, cleaning shifts) apply unchanged.
- Without a token the site renders the two sample properties in `data/fixtures/properties.json` (real public fields only).

## Rules
- **Prices only from the direct quote.** Hospitable's calendar endpoint returns the Airbnb listing's nightly rates (provider `airbnb-official`), not Hospitable Direct's: on 11-04 the direct quote for Prairie-Luxe Dec 1-4 was $333.10 for the nights vs $270 summed from the calendar, more than the 3% direct markup explains (likely Airbnb-only discounts in the calendar figure; MDP checking). Never show calendar `price` to guests; use it for availability only. Every amount on the site or in Ask Pique comes from `priceStay()`.
- **Public fields only.** `toPublicProperty()` in `src/lib/properties.ts` is an allowlist. Hospitable's property payload also carries the house manual (building, pool, garage and door codes), wifi and streaming logins and the iCal feed; never request `include=details` and never pass a raw Hospitable object to a page, route, sitemap, llms.txt or JSON-LD. Reviews: only `public` text and rating, never `private` feedback. Coordinates are rounded to ~1 km; no street address.
- **Listing copy = the Airbnb copy** (MDP 11-04: titles and descriptions exactly as on Airbnb). Hospitable keeps a team default plus per-channel overrides, and the team edits the Airbnb override, so `getPropertyCopy()` reads `/properties/{uuid}/details` and takes direct → Airbnb → default for the title, summary, space overview, neighbourhood and transit (never house manual, wifi or directions, which come in the same response). If that call fails the plain property text is used. `cleanDescription()` still drops lines that only make sense on Airbnb (the Airbnb app, Airbnb insurance) and the booking disclaimer.
- **Home names** (Michael Stead 11-25): the Airbnb title is a keyword list, so `homeName()` shows only the name ("*5BD Jungle Oasis *HotTub*BBQ" → "Jungle Oasis"); Hospitable's Direct title is a copy of the Airbnb one, so all titles go through it; a plain Direct title (no * | ! or emoji) passes through unchanged. Counts say "stays", not "homes" (units and whole-house listings are separate stays).
- **Prices are shown like Airbnb** (Michael Stead 11-25): one stay price (rate + cleaning + extra-guest and pet fees + discounts, Hospitable's `total_without_taxes`), then taxes, then the total. Hospitable's checkout still shows its own breakdown. Ask Pique also gets the breakdown (`included_in_stay`) for when a guest asks.
- **Hidden photos**: `data/hidden-photos.json` lists Airbnb marketing tiles (QR codes, Best in Edmonton badges, wifi speed tests) found by scanning every listing on 11-25; new ones added in Hospitable later aren't caught until it's re-run.
- **Info and policy pages** (about, contact, faq, cancellation, house-rules, damage-protection, pets, terms, privacy, cookies, accessibility) all come from `src/content/info.ts`, rendered by `src/app/[info]/page.tsx`. Policies are Laurice's 10-19 answers, the rental agreement and Michael's Truvi wording (up to $700, included in the stay). The cancellation policy is Hospitable Direct's, read from its checkout 11-25: `src/lib/cancellation.ts` holds it and writes the line under Book now. Change both if Hospitable's changes. Ask Pique's prompt repeats the key policies.
- Property URLs end in the first 8 characters of the Hospitable id; a renamed listing 308-redirects to its new slug. Don't change the slug format without redirects.
- Every page must stay readable without JS (crawlers and AI assistants): animations only toggle classes on server-rendered content.

## Ask Pique (chat)
- `src/components/AskPique.tsx` (floating chat, conversation kept in sessionStorage) → `POST /api/chat` (`src/app/api/chat/route.ts`): Claude (`claude-opus-5-5`, effort low, server-side fallbacks) in a manual tool loop, at most 6 tool rounds, 20 guest messages per chat, 1,000 characters per message, rough per-IP limit.
- Rules live in `src/lib/chat/prompt.ts` (MDP 10-13): may quote and explain prices and point out real discounts (longer stay, other dates, cheaper similar home) from `price_stay`, **never negotiates**; hands off to call/text (1-780-230-0267, `SITE.phone`) for deals, existing bookings, exceptions, upset guests or anything unsure. No age rule (none of the 94 listings has one).
- Tools (`src/lib/chat/tools.ts`) only read the public allowlisted data the pages use: `search_homes` (same `searchHomes()` as /search), `get_home`, `price_stay` (same `priceStay()` as the booking box, max 6 per answer), `offer_contact` (shows Call / Text with a pre-written text). The reply keeps only links to our own pages.
- Every turn is saved to the ops Supabase project through `record_website_chat_turn()` (pique-ops migration `20261013010000_website_chats.sql`; tables `website_chats`, `website_chat_messages`, staff-readable): the site holds only the public anon key plus `WEBSITE_CHAT_SECRET`, which the function checks against a stored hash. Saving runs after the reply and never blocks it.
- Env: `ANTHROPIC_API_KEY` (without it the chat answers "isn't switched on yet" with Call / Text), `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `WEBSITE_CHAT_SECRET`.
